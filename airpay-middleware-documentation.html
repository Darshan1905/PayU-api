Airpay Middleware API

Base URL: https://connect.pavokart.com · API Key: airpay-pavokart-demo-key · Simple Transaction v1.0.0

Overview

Same domain as PayU/Mswipe. Airpay Simple Transaction redirects the customer to Airpay’s payment page. No auto customer generator.

MethodEndpointDescription
POST/api/airpay/initiateCreate payment redirect URL
POST/api/airpay/statusVerify payment status
GET/api/airpay/notificationsWebhook log
POST/webhook/airpayAirpay IPN (no API key)

Headers

Accept: application/json
X-API-Key: airpay-pavokart-demo-key
Content-Type: application/json

IP whitelist also applies. Webhook does not use API key.

1. Initiate payment

POST/api/airpay/initiate

Full URL
https://connect.pavokart.com/api/airpay/initiate
Body
{
  "requestAmount": 499.00,
  "firstName": "Rahul",
  "lastName": "Sharma",
  "email": "rahul@example.com",
  "phone": "9876543210",
  "callbackUrl": "https://your-app.com/webhook"
}

Open checkoutUrl from the response. Customer is redirected to Airpay hosted page.

2. Payment status

POST/api/airpay/status

Body
{
  "txnId": "AP123T250910120000"
}

3. Notifications

GET/api/airpay/notifications?limit=20

4. Webhook / IPN

POST/webhook/airpay

https://connect.pavokart.com/webhook/airpay

Configure this URL in the Airpay merchant panel as the IPN callback.
